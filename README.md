# NimiqSplit ⚡

> **Fast, frictionless bill-splitting on the Nimiq network.** Split dining tabs, group roadtrips, and household bills in seconds with zero-friction crypto payments.

Built for the **Nimiq Mini Apps Competition**.

---

## 🌟 Highlights & Features

1. **Live CoinGecko Price Ticker**: Automatically converts expense amounts between **USD**, **NIM**, and **USDT** in real time.
2. **Instant Settlement**: Generate dynamic QR codes containing standard Nimiq payment URIs (`nimiq:NQ...`) with amount & message preloaded.
3. **Nimiq Hub & Nimiq Pay Ready**: Pay with 1-click via the official Nimiq Hub browser checkout or scan via the Nimiq Pay mobile app.
4. **Expense Management**: Add multiple payers, track who paid what, and calculate minimal debts with one tap.
5. **Persistent History**: All group expenses are saved locally in browser storage so you never lose track.
6. **Built-in Guide**: Complete *About & Instructions* modal explaining how the mini app works.
